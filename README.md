# IBM Data Visualization Final Project

## 📊 Automobile Sales Analysis & Dashboard

This project is the final assignment for the **IBM Data Visualization with Python** course. The project analyzes historical automobile sales data to understand the impact of **economic recessions, advertising expenditure, unemployment rate, vehicle type, GDP, and seasonality** on automobile sales.

The project is divided into two major parts:

* **Part 1:** Data visualization using Matplotlib, Seaborn, and Folium
* **Part 2:** Interactive dashboard using Plotly and Dash

---

## 🎯 Project Objectives

* Analyze historical automobile sales trends.
* Compare automobile sales during recession and non-recession periods.
* Study the relationship between advertising expenditure and automobile sales.
* Analyze sales performance across different vehicle types.
* Visualize the impact of GDP and unemployment on automobile sales.
* Study seasonal patterns in automobile sales.
* Build an interactive dashboard for yearly and recession-period analysis.

## 📊 Part 2 – Interactive Dashboard

An interactive dashboard was created using **Plotly and Dash**.

The dashboard provides two statistical report modes:

### 1. Recession Period Statistics

The dashboard displays:

* Average automobile sales fluctuation during recession periods
* Average automobile sales by vehicle type
* Total advertising expenditure by vehicle type
* Automobile sales analysis by vehicle type during recession

### 2. Yearly Statistics

After selecting a specific year, the dashboard displays:

* Automobile sales over the years
* Monthly automobile sales for the selected year
* Average vehicles sold by vehicle type
* Total advertising expenditure by vehicle type

---

## 🖥️ Dashboard Components

The dashboard includes:

* **Statistics dropdown**

  * Yearly Statistics
  * Recession Period Statistics

* **Year dropdown**

  * Allows selection of a specific year for yearly analysis
  * Disabled when Recession Period Statistics is selected

* **Interactive Plotly graphs**

  * Line charts
